# Blackjack (Python)

A terminal Blackjack game written in Python. Play against a dealer AI with hit, stay, and split, and keep a running tally of wins across rounds.

## Features
- Four-suit deck with face cards and aces (aces count as 11 or 1 automatically)
- Dealer AI that draws to the standard house rule
- **Split** when your first two cards match, playing each hand separately
- Win tracking for player vs. dealer, with replay prompt

## Run it
```bash
python Blackjack_Logans.py
```
Requires Python 3 — no extra packages.
